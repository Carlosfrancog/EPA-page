# EPA-page

Este repositório publica uma apresentação acadêmica do EduPredict Analytics. Mantenha TGI I e TGI II distintos. Trate planos como planos, experimentos sintéticos como experimentos e resultados históricos no contexto em que foram reportados.

O site está em `site/` e usa HTML/CSS/JS estáticos. Use links relativos para funcionar em GitHub Pages sob `/EPA-page/`. Os documentos técnicos gerados por `scripts/sync-epa.py` são propostos por PR e exigem revisão antes de publicação. Não altere PDFs oficiais silenciosamente.
